     KOMPOSOS-MOF Inverse Design System - Implementation Plan

     Context

     Problem: Heather Kulik (MIT) needs a system to generate novel 22-atom MOF linkers that pass strict categorical reasoning constraints. Current
     molecular generation systems hallucinate impossible molecules or produce structures that violate synthesizability, toxicity, stability, or activity
      requirements.

     Solution: Build a full inverse design pipeline integrated with KOMPOSOS's existing materials science reasoning engine. The system will:
     1. Download 103K+ MOF structures from Materials Project
     2. Extract organic linkers and filter to 22-atom molecules
     3. Generate novel 22-atom linker candidates (initially via combinatorial/constraint-based search, with GNN training as Phase 2)
     4. Score each candidate with 5 KOMPOSOS verdicts (synthesizability, toxicity, stability, activity, electrical conductivity)
     5. Use ZFC + CAT dual-engine reasoning to classify as AGREE/HOLLOW/ORPHAN/REJECT
     6. Return only AGREE candidates ranked by morphism integrity

     Integration: This extends the existing MOF bridge (30 MOFs, 5 scorers, 83 tests) with molecular-level inverse design, following established
     patterns from molecular_bridge, composition_engine/mp_loader, and zfc/bridge.

     Architecture Overview

     Materials Project API (103K MOFs)
             ↓
     MP MOF Loader (mof_bridge/mp_mof_loader.py)
       - Download CIF structures

     class LinkerGenerator:
         def __init__(self, known_linkers: List[MOFLinker]):
             """Initialize with database of known 22-atom linkers."""
             self.known_linkers = known_linkers
             self.known_smiles = {l.smiles for l in known_linkers}

         def generate_candidates(
             self,
             n_candidates: int,
             application_context: str,
             functional_groups: Optional[List[str]] = None,
             exclude_elements: Optional[List[str]] = None,
         ) -> List[str]:
             """Generate novel SMILES strings via combinatorial search.

             Strategy 1: Functional group substitution
             - Take known linker backbones
             - Swap functional groups (–OH, –NH2, –COOH, –F, –Cl, etc.)
             - Keep heavy atom count == 22

             Strategy 2: Ring fusion
             - Combine 2 smaller rings (benzene + pyridine → quinoline)
             - Add bridging atoms to reach 22

             Strategy 3: Saturation/desaturation
             - Add/remove double bonds
             - Maintain 22 heavy atoms

             Returns:
                 List of SMILES strings (validated by RDKit, novel only)
             """

     Validation:
     - RDKit Chem.MolFromSmiles() succeeds
     - Heavy atom count == 22
     - SMILES not in known_smiles set (novelty check)
     - No radical species, valid valences

             """Run dual-engine reasoning on a linker candidate.

             Steps:
             1. Extract atomic descriptors

             4. Combine: Classify each verdict as AGREE/HOLLOW/ORPHAN/REJECT
             5. Return result
             """

     5 Verdict Modules (each returns AGREE/HOLLOW/ORPHAN/REJECT):

     1. Synthesizability
     - ZFC Rules:
       - All atoms have valid valence
       - No strained rings (ring strain < 20 kJ/mol)
       - Bond orders match hybridization
       - No unusual oxidation states
     - CAT Check:
       - Retrosynthetic path exists? (heuristic: known functional group combos)
       - Morphism: reactants → product composes?
     - AGREE: All bonds valid + known synthesis routes
     - HOLLOW: Looks valid but has hidden strain/instability
     - ORPHAN: Forced by valence rules but no synthesis path
     - REJECT: Both fail

     2. Toxicity
     - ZFC Rules:
       - No known toxic groups (isocyanate, diazo, azide, peroxide)
       - No heavy metals (Pb, Hg, Cd, As)
       - Electrophilicity < threshold (from partial charges)
     - CAT Check:
       - Structural similarity to known non-toxic molecules
     - AGREE: No toxic groups + similar to safe molecules
     - HOLLOW: Similar to safe molecules but has toxic substructure
     - ORPHAN: Logically forced non-toxic but structurally unknown
     - REJECT: Both fail

     3. Stability
     - ZFC Rules:
       - Bond strengths > 200 kJ/mol (no weak bonds)
       - No strained rings
       - Aromatic systems present (stabilization)
     - CAT Check:
       - Decomposition pathways blocked?
       - Similar to known stable linkers?
     - AGREE: Strong bonds + no decomposition paths
     - HOLLOW: Thermodynamically stable but kinetically labile
     - ORPHAN: Logically stable but no stability data
     - REJECT: Both fail

     4. Activity/Selectivity (application-dependent)
     - ZFC Rules (for application="breath_VOC_sensing"):
       - Polar functional groups present (O, N with high EN)
       - Aromatic rings for π-π interactions
       - Pore-forming geometry (branched, not linear)
     - CAT Check:
       - Similar to known VOC-active linkers?
     - AGREE: Functional groups + similar to active MOFs
     - HOLLOW: Has groups but geometry prevents access
     - ORPHAN: Logically active but no experimental precedent
     - REJECT: Both fail

     5. Electrical Conductivity
     - ZFC Rules:
       - Conjugated π-system length > 6 atoms
       - Aromatic content > 50%
       - Heteroatom doping (N, S for electron delocalization)
     - CAT Check:
       - Orbital overlap composes into extended state?
       - Similar to known conductive linkers?
     - AGREE: Extended conjugation + precedent
     - HOLLOW: Conjugated but localized (no extended state)
     - ORPHAN: Logically conductive but no measurements
     - REJECT: Both fail

     Morphism Integrity (CAT layer):
     def compute_morphism_integrity(descriptors: Dict) -> float:
         """Check if atomic descriptors compose consistently.

         For each bond (i, j):
         - Expected bond type from hybridization of atoms i, j
         - Actual bond type from RDKit
         - If mismatch: contradiction_count += 1

         morphism_integrity = 1.0 - (contradictions / total_bonds)
         """
