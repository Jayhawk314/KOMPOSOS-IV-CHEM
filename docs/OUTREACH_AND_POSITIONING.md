## PART I: HOW TO POSITION EACH VERSION

### The Drug Discovery Core (LAMBDA-max) -- GIVE IT AWAY FREE

**Why free**: This is your credibility engine. The cancer drug repurposing
tool is what makes people take you seriously. Nobody pays an unknown solo
developer for drug discovery software. But if you give it away and it helps
one researcher find one lead, that story is worth more than any price tag.

**How to package**:
- **Docker container** (priority 1): Eliminates "doesn't work on my machine."
  One command: `docker run komposos-iii --protein EGFR --mutation L858R`
- **PyPI package** (priority 2): `pip install komposos-iii` for Python users
- **Streamlit web UI** (priority 3): So clinicians don't need a terminal
- **GitHub repo** stays public, MIT or Apache 2.0 license

**Who it's for**: Cancer researchers, bioinformaticians, patient advocacy
groups, rare disease organizations, anyone who needs drug repurposing leads
with traceable evidence chains.

**The pitch**: "Free, open-source drug repurposing tool. You type a mutation,
it tells you what drugs might work and shows you the biological proof chain.
Every link cites DrugBank, COSMIC, or FDA records. Runs on your laptop."
