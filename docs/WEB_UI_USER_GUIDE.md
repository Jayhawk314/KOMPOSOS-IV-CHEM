## 2. Page 1: Compatibility Oracle (Categorical Runtime)

**Purpose**: Verify material compatibility via morphism composition and COG audit.

### How to Use
1. **Select Domain**: Pick from 8 bridges (Battery, Polymer, Metal, etc.).
2. **Select Materials**: Choose Source and Target objects.
3. **Select COG Audit Tier**: 
   - **Tier 1**: Path composition (Fast).
   - **Tier 2**: Sheaf coherence (Standard).
   - **Tier 3**: ZFC Dual-Engine audit (Rigorous).
   - **Tier 4**: Ricci Flow/Topological audit (Deep - High Latency).
4. Click **"Execute Morphism"**.

### What You Get
- **Morphism Status**: EXISTS (Green) or BLOCKED (Red).
- **Quantale Weight**: Composite confidence score (0-1).
- **Dual-Engine Verdict**: **AGREE**, **HOLLOW**, **ORPHAN**, or **REJECT**.
- **Detailed Ensemble Votes**: An interactive audit trail showing exactly how every mathematical strategy voted, including simplicial similarity and fibration transport evidence.
- **Energy Score**: Measures the "surprise" or stability of the interaction.

## 3. Page 2: OPTIMUS Optimizer

**Purpose**: Find optimal material property balance using game-theoretic Nash equilibrium.

### How to Use
1. **Define Objective**: Select primary property (e.g., Conductivity).
2. **Define Constraints**: Select secondary properties to balance (e.g., Stability, Cost).
3. **Run Nash Search**: OPTIMUS finds the point where all property "players" are in equilibrium.
4. **Intermediate Search**: Toggle "Discovery Mode" to find factorizations (bridge materials) that improve the system.
